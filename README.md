# Machine-learning prediction of antibiotic adsorption capacity

This repository contains the curated data, reproducible modeling notebooks, and frozen analysis outputs for prediction of experimental antibiotic adsorption capacity, **qe (mg g⁻¹)**, using **Random Forest (RF)** and **XGBoost (XGB)** regression.

The repository is intentionally focused on **data and model-analysis artifacts**. Interpretation, model-selection decisions, and manuscript discussion are not finalized here.

## Dataset construction

The literature workflow is documented in `supplementary/publication_screening_workflow.xlsx`. The final modeling dataset contains **213 experimental observations from 40 source publications**. The compact modeling table is `data/dataset.csv`.

The final full-text inclusion rules required a source-linked, single-component aqueous adsorption experiment with the mandatory model variables available for the same experiment. Experimental **qe** values were retained when directly reported numerically or when transparently calculable from explicit experimental quantities. Fitted isotherm capacities (`qmax`/`Qm`), fitted kinetic `qe,cal`, and values estimated from graphs were excluded.

An independent **19-observation external-validation dataset** is provided as `data/dataset_EV.csv`, with full source-level provenance in `data/19_records_external_validation_final.xlsx`.

## Model variables

| Variable | Description |
|---|---|
| `MLOGP` | Antibiotic molecular lipophilicity descriptor |
| `C0_mg_L` | Initial antibiotic concentration (mg L⁻¹) |
| `pH` | Solution pH |
| `Temperature_C` | Temperature (°C) |
| `Contact_time_min` | Contact time (min) |
| `Dose_g_L` | Adsorbent dose (g L⁻¹) |
| `BET_m2_g` | BET specific surface area (m² g⁻¹) |
| `qe_mg_g` | Experimental adsorption capacity, target variable (mg g⁻¹) |

## Evaluation terminology

Both notebooks use the same evaluation design:

- **Training** — 143 records used for model fitting.
- **Validation** — fixed 70-record hold-out subset; not used for model fitting or internal cross-validation.
- **External validation** — independent 19-record dataset.
- **Internal cross-validation** — repeated 5-fold cross-validation ×10 on the Training set only, producing 50 validation-fold evaluations. CV metrics are reported as **mean ± sample standard deviation** across those 50 folds.

| XGBoost | Validation | 0.731955 | 28.09612 | 51.50103 |

The table reports the frozen outputs generated by the notebooks included in this repository. No model-ranking conclusion is imposed here.

## Provenance and auditability

The full XLSX datasets retain DOI-level provenance and methodological notes for each experimental record. The compact CSV files are model-ready projections of those audited records.

PDF source publications are intentionally **not distributed in this repository**.
